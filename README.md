# Portfólio Terceiro Setor — Agência Quebra

Página estática (HTML + CSS + JS, sem dependências externas).

## Publicar no GitHub Pages

1. Envie todo o conteúdo desta pasta para a raiz de um repositório (mantendo `index.html` e a pasta `assets/`).
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. A página fica disponível em `https://<usuario>.github.io/<repositorio>/`.

## Estrutura

- `index.html` — introdução, "Por que a Quebra" (quem somos, três cases, fechamento) e assinatura.
- `assets/css/style.css` — tokens, fontes (Bricolage e Manrope, locais) e componentes.
- `assets/js/main.js` — barra de progresso, animações de entrada e acordeões.
- `assets/img/`, `assets/fonts/`, `assets/docs/` — mídias, fontes e PDF do case BRK.

A página está com `noindex, nofollow`; remova essa meta tag no `index.html` se quiser que ela apareça em buscadores.
